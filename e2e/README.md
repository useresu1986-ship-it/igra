# Браузерные тесты

Установка зависимостей и Chromium после клонирования:

```sh
npm ci
npx playwright install chromium
```

Запуск:

```sh
npm run test:e2e
```

Playwright автоматически запускает HTTP-сервер на http://127.0.0.1:4173,
открывает `/index.html` в Chromium и останавливает сервер после проверки.
Порт 4173 должен быть свободен.

Smoke-тест проверяет отображение игры, инициализацию счётчиков, отсутствие
необработанных JavaScript-исключений (включая отклонённые Promise) и сообщений
`console.error` за время загрузки.

`gameplay.spec.js` проверяет новую жизнь через подтверждение сброса, восемь
основных экранов, первую смену курьера, доход и журнал, сон, сохранение
прогресса после перезагрузки и открытие товарного бизнеса за заработанные деньги.
Для накопления капитала тест решает задачу веб-разработчика через кнопки мини-игры
и отдыхает при нехватке ресурсов. Суммы выплат случайные; допускается до 40 смен.
Все действия проходят через интерфейс, без изменения игрового состояния,
localStorage, генератора случайных чисел или подмены сетевых ответов.

Каждый тест изолирован отдельным browser context. В игровых сценариях ошибки
JavaScript и `console.error` проверяются на протяжении всего теста.
Отдельный регрессионный тест проверяет перезагрузку с сохранённой вкладкой
товарного бизнеса; обнаруженные ошибки не помечаются как ожидаемый успех.

`tabs.spec.js` проверяет сохранение и восстановление всех 34 вкладок после
перезагрузки. Перед каждой проверкой игрок проходит смену курьера: после reload
должны сохраниться экран, активная вкладка, деньги, день, энергия и навык.
Отдельная проверка сопоставляет список тестов с реальными кнопками навигации,
чтобы новые вкладки не оставались без регрессии.

Инициализация игры состоит из регистрации модулей и первого показа экрана.
Модули не вызывают `render()` при подключении: первый вызов делает
`initializeGame()` в `game.js` на событии `DOMContentLoaded`, когда все
синхронные скрипты из `index.html` уже выполнились. Сохранённая вкладка
проверяется по готовой навигации; отсутствующая вкладка заменяется на `home`.
Вызовы `render()` при действиях игрока работают как раньше.

Для запуска с видимым окном браузера: `npm run test:e2e:headed`.
При падении снимок экрана и trace сохраняются в `test-results/`.
HTML-отчёт: `playwright-report/index.html` (`npx playwright show-report`).
Ошибки JavaScript и журнал накопления капитала прикладываются к отчёту.
Результаты перезаписываются при следующем запуске.

Только файлы `e2e/**/*.spec.js` считаются браузерными тестами.
Существующие Node.js-тесты `tests*.js` запускаются отдельно, как раньше.
